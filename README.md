# Dream Treehouse site

The privacy policy and support pages for Dream Treehouse, an iPhone game by Fresh Field, LLC, served by GitHub Pages:

- https://dylanfairfield.github.io/dream-treehouse-site/
- https://dylanfairfield.github.io/dream-treehouse-site/privacy/
- https://dylanfairfield.github.io/dream-treehouse-site/support/

Plain HTML and one stylesheet, no build step, no scripts, no cookies, no outside requests. The game's code lives in a separate private repository. Keep the privacy policy matched to what the game actually does, and change its date when it changes.
